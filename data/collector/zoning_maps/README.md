# Zoning Maps Data Collector

This collector gathers zoning maps from a variety of municipal sources.

This will collect two types of data: 1) zoning geospatial files and 2) zoning map static images (pdf, jpg, png, etc.).

Remind that some cities will not have zoning geospatial file data available. 

Although the main purpose of this collector is to collect zoning maps to be inputted into our postgis database, another purpose of this collector is to collect the zoning map static images and geospatial files to train a vision model to create digitized zoning maps from static zoning images.
