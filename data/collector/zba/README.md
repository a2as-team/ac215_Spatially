# ZBA Data Collector

This data collector is responsible for collecting zoning board approval data from the US Census Bureau.

The ZBA seems to have video data and summary data for each hearing. We should ideally transcribe the videos and then use the summary data to fill in the gaps, especially the locations and so on.

## 1. Boston

#### ZBA Hearing Records

- URL: https://www.boston.gov/departments/inspectional-services/zoning-board-appeal#reviews
This is the official website of the Boston Zoning Board of Appeals that provides hearing records for zoning board appeals.
- Another URL: https://www.bostonplans.org/planning-zoning/zoning-board-of-appeal
- Legistar URL: https://boston.legistar.com/DepartmentDetail.aspx?ID=46304&GUID=5E333EEA-5D40-458B-A8F4-1D21B962500E
- Development Review: https://www.bostonplans.org/projects/development-projects/the-innovation-and-design-building
- Development Project: https://www.bostonplans.org/projects/development-projects?viewall=1
- - Document center: https://www.bostonplans.org/document-center?searchtext=&searchmode=anyword&doctype=&neighborhood=&project=&department=&program=&language=&date=&page=5
- Article 80 locations: https://boston.maps.arcgis.com/home/item.html?id=653106e7f9d24d8bba8b47c10aabc95d
- Article 80 Records library: https://apps.bostonplans.org/recordslibrary/
