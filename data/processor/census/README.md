# Census Data Processor

This processor ingests ACS (American Community Survey) census data from CSV files into the database.

## Overview

The Census Processor reads CSV files generated by the Census Collector from Google Cloud Storage and ingests them into PostgreSQL database tables according to the schema defined in the project README.

## Database Schema

The processor creates and populates the following tables:

### CENSUS_TRACT
Stores geographic tract information.
- `geoid` (PK): Geographic identifier
- `geom`: PostGIS geometry (MultiPolygon)
- `created_at`: Timestamp

### ACS_TABLE
Stores ACS table definitions.
- `acs_table_id` (PK): Table code (e.g., "DP04", "S1901")
- `title`: Human-readable table title
- `topic`: Table topic/category
- `table_type`: Type of table (Data Profile, Subject Table, etc.)
- `description`: Detailed description

### ACS_RELEASE
Stores ACS release information linking tables to specific years and datasets.
- `acs_release_id` (PK): Unique release identifier
- `acs_table_id` (FK): References acs_table
- `year`: Survey year
- `dataset`: Dataset path (e.g., "acs/acs5/profile")
- `vintage`: Vintage year

### ACS_VARIABLE
Stores variable definitions for each table.
- `variable_id` (PK): Unique variable identifier
- `acs_table_id` (FK): References acs_table
- `name`: Variable name
- `concept`: Variable concept/description

### ACS_VALUE
Stores actual census data values.
- `acs_value_id` (PK): Auto-increment primary key
- `geoid` (FK): References census_tract
- `acs_release_id` (FK): References acs_release
- `variable_id` (FK): References acs_variable
- `value`: Numeric value
- `ingested_at`: Timestamp of ingestion

## Data Flow

1. **Download**: Processor downloads CSV files from GCS bucket
2. **Parse**: Reads manifest.csv to identify all available files
3. **Ingest Metadata**: Creates/updates ACS_TABLE, ACS_RELEASE, ACS_VARIABLE records
4. **Ingest Data**: Inserts census tract and value records
5. **Commit**: Commits data in batches for efficiency

## Usage

### Standalone Usage

```bash
python data/processor/census/run.py --city boston
```

### Test Mode

Process only the first 3 files for testing:

```bash
python data/processor/census/run.py --city boston --test
```

### As Part of Pipeline

The processor is typically run as part of a Vertex AI pipeline:

```bash
# Run complete census pipeline (collector + processor)
python workflow/cli.py --city boston --pipeline census

# Run only the processor
python workflow/cli.py --city boston --pipeline processor-census
```

## Environment Variables

Required environment variables:

- `APP_DB_NAME`: PostgreSQL database name
- `POSTGRE_USER`: PostgreSQL username
- `POSTGRE_PASSWORD`: PostgreSQL password
- `POSTGRE_HOST`: PostgreSQL host
- `POSTGRE_PORT`: PostgreSQL port (default: 5432)
- `GCS_BUCKET_NAME`: GCS bucket name
- `GCP_PROJECT`: GCP project ID

## Table Metadata

The processor includes metadata for common ACS tables:

### Housing Tables
- **DP04**: Selected Housing Characteristics
- **S2503**: Financial Characteristics
- **S2501**: Occupancy Characteristics

### Income Tables
- **S1901**: Income in the Past 12 Months
- **S1903**: Median Income
- **S1701**: Poverty Status

### Employment Tables
- **S2301**: Employment Status
- **S2403**: Industry by Sex
- **S2404**: Industry by Sex for Full-Time Workers

### Demographics Tables
- **DP02**: Selected Social Characteristics
- **DP05**: Demographic and Housing Estimates
- **S1101**: Households and Families

### Other Tables
- **S0701**: Geographic Mobility
- **S0801**: Commuting Characteristics
- **S0802**: Means of Transportation
- **S0804**: Detailed Transportation Characteristics
- **S1501**: Educational Attainment
- **S2201**: Food Stamps/SNAP

## Geographic Levels

The processor supports different geographic aggregation levels:

- **State**: geoid = 2-digit state FIPS code
- **County**: geoid = 5-digit state+county FIPS code
- **Tract**: geoid = 11-digit state+county+tract FIPS code

The geographic level is automatically detected from the CSV columns.

## Error Handling

- **Missing variables**: Logged as warnings, processing continues
- **Invalid values**: Non-numeric values are skipped
- **Duplicate tracts**: ON CONFLICT DO NOTHING prevents duplicates
- **Failed batches**: Individual failures are logged, processing continues

## Performance

- Batch size: 100 records per commit
- Progress logging: Every 50 inserted values
- Memory efficient: Processes files one at a time
- Database indexes: Created on all foreign keys and commonly queried columns

## Troubleshooting

### No CSV files found
- Check that census collector ran successfully
- Verify GCS bucket path: `census/{city}/`
- Check GCS permissions

### Database connection errors
- Verify all POSTGRE_* environment variables are set
- Check database host is accessible
- Ensure database user has CREATE TABLE permissions

### Duplicate data
- The processor deletes existing city data before ingestion
- Use ON CONFLICT clauses to prevent duplicates
- Check census_tract and acs_value tables for existing data
