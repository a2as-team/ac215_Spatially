# Development Plans Collector

This collector gathers development plan documents from a variety of municipal sources.


## Boston Plans

**Resource URL:**  
[BPDA Records Library](https://apps.bostonplans.org/recordslibrary/)

Boston makes public a wide array of development plans. Projects are generally classified as *large* (Article 80, PDA) or *small* (SPRA).

---

### Large Projects (Article 80 / PDA)

For major projects, collect the following documents:

| Document                                         | Description                                                               |
|--------------------------------------------------|---------------------------------------------------------------------------|
| Planned Development Area (PDA) Development Plan   | Comprehensive plan incl. site plan, building elevations, and more         |
| PDA Development Plan Fact Sheet                  | Summarizes the project’s purpose and key information                      |
| Project Notification Form (PNF)                  | Project details: purpose, location, etc.                                  |
| Letter of Intent (LOI)                           | Formal intent to submit or undertake project                              |
| BPDA Board Decision                             | Board’s ruling, especially re: zoning relief                              |

---

### Small Projects (SPRA)

For projects classified as SPRA (Small Project Review Application):

| Document                                        | Description                                                               |
|-------------------------------------------------|---------------------------------------------------------------------------|
| Small Project Review Application (SPRA)         | Project details: purpose, location, etc.                                  |
| BPDA Board Decision                            | Board’s ruling, particularly regarding zoning relief                      |

---

**Notes:**
- *Article 80* filings are for large-scale developments; *SPRA* for smaller projects.
- BPDA = Boston Planning & Development Agency
