# ZBA Data Collector

This data collector is responsible for collecting zoning board approval data from the US Census Bureau.

## 1. Boston

#### ZBA Hearing Records

- URL: https://www.boston.gov/departments/inspectional-services/zoning-board-appeal#reviews
This is the official website of the Boston Zoning Board of Appeals that provides hearing records for zoning board appeals.
